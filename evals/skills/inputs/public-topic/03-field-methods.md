# Pilot field sheet and methods

ORIGINAL SYNTHETIC EVALUATION MATERIAL; fixed invented observations for this exercise only.

Document ID CW-03; signed 2031-06-01; fictional Canal Ward field team.

[M1] Panel stops were chosen because mounting rails already existed. Comparison stops were the nearest stops without rails. Assignment was not random. There are no before-installation readings.

[M2] Sensors were read once per weekday at 17:00 for seven days. Three panel-stop sensors and all four comparison sensors were shielded from direct sunlight. The sensor at panel stop P4 was mounted inside the panel's metal bracket. The same handheld reference unit was not available every day.

[M3] The archived stop-level seven-day means (°C) are:

| stop | panels | mean air reading |
|---|---|---|
| P1 | yes | 30.2 |
| P2 | yes | 30.4 |
| P3 | yes | 30.3 |
| P4 | yes | 28.3 |
| C1 | no | 31.5 |
| C2 | no | 31.7 |
| C3 | no | 31.9 |
| C4 | no | 32.1 |

[M4] Comfort cards were offered by volunteers stationed only at panel stops. Cards were anonymous; repeat riders could submit cards on multiple days. No passenger counts, dwell times, humidity, wind, radiant heat or illness measurements were recorded.
