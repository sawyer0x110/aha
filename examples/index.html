Why does Greenland look so large on a map?

Africa's reported area is about fourteen times Greenland's. Move Greenland toward the equator by rigid rotation on a sphere: its area stays the same while its footprint on the fixed Mercator map changes.

03

Why can one emoji make a CPython string almost four times larger?

Look inside the storage for one hundred thousand English characters: adding U+1F600 widens every character slot in the new string, while the UTF-8 encoding grows by only four bytes. Object memory and encoded payload are different things.

The file is deleted. Why does the Docker image still contain its bytes?

Uncover immutable image layers: a deletion marker hides a path but retains data in the underlying layer. Compare creating and deleting a new temporary file within the same RUN. The 100 MB is an assumed payload, not a measured image size.

为什么一个 emoji 能让 CPython 字符串接近四倍大？

把十万个英文字符的存储拆开来看：加入 U+1F600 后，新字符串的每个字符槽都变宽，但 UTF-8 编码只增加四字节。对象内存与编码载荷不是一回事。
