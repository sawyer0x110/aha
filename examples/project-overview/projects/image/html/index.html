Same meaning. Different reading situations.

Explore a rich offline page, diagrams and purposeful controls.

PNG

VIDEO

Follow frame-driven motion timed to measured speech.

Each format is authored separately. There is no automatic “all” command.

Approve execution. Approve voice disclosure separately.

HTML packaging does not run author scripts. Browser capture and Node slides do; Node is not an OS sandbox. Edge TTS also needs approval of the exact current narration plan.

A hash is a fingerprint, not a fact checker.

Rebuild when source changes. Then review the evidence, actual layout, editing, interaction and playback. Render success does not establish human understanding.
