# Aha：从证据到可编辑的解释

Aha 用两个便携技能分开处理调研与解释创作，再通过运行时检查研究、源码、计划和产物身份。它不替代证据判断、语言审读或实际作品验收。

当前四种项目使用同一份[研究身份](research/manifest.json)。[研究报告](research/report.md)固定在本地提交 `31ff1331b402bc80c3a731ca470000a77dcd594f`，其树与当时 main 的 `c98b1927` 一致；新图仅复用其中有关项目与媒介的主张。研究快照不会因发布目录或当前 runtime 版本更新而自动变化。复现方式、持久媒体环境与许可要求见[统一说明](../README.md)。

### 本目录旧版视频的配音来源

`overview.mp4` 为 1280×720、30fps、4453 帧。十五段英文录音来自经单独批准的 `edge-tts==7.2.8`、`en-US-AriaNeural`、`+0%`。自然时长 148.43 秒超过初始 90–120 秒范围，用户接受完整内容和新时长后，批准 `provided-audio` 本地导入；原始语音字节未变。

[当前音频清单](audio/manifest.json)、[原配音计划及记录](audio-origin/)与[视频收据](overview.mp4.json)分别保留绑定和来源。只外发了已批准旁白及必要声线参数，没有外发研究、源码或截图。服务条款及其他再分发用途需使用者自行确认。
