# Aha：从证据到可编辑的解释

Aha 用两个便携技能分开处理调研与解释创作，再通过运行时检查研究、源码、计划和产物身份。它不替代证据判断、语言审读或实际作品验收。

## 主线与快照

从研究到媒介的关系、快照与新证据、四种媒介的不同用途、ANC 压力叠加和 Git 状态选择，再讲权限、图像尺寸与目录职责。深色首尾强调主线，浅色正文解释关系；视频机制会变化，PPT 使用可编辑对象与逐页展开，不宣称含页内动画。

[研究报告](research/report.md)固定在本地提交 `31ff1331b402bc80c3a731ca470000a77dcd594f`，其树与当时 main 的 `c98b1927` 一致。嵌入的 ANC/Git 界面取自这个快照，**不是本次重新发布的两例新版页面截图**。其中 Git 展示旧版已有记录，不意味着本次运行了新的 Git 实验。研究快照不会因发布目录更新而自动变化。

PNG 保持 1080×1800，缩短关系文案、增大必要文字、补充曲线标识，并复查 390px／540px 显示宽度；没有用更大画布掩盖阅读问题。PPT 保留原生文字、图表和形状。它与 PNG、HTML、视频分别创作，不是网页截图转幻灯片或逐页录屏。

## 配音与验收

视频为 1280×720、30fps、4453 帧。十五段英文录音来自经单独批准的 `edge-tts==7.2.8`、`en-US-AriaNeural`、`+0%`。自然时长 148.43 秒超过初始 90–120 秒范围，用户接受完整内容和新时长后，批准 `provided-audio` 本地导入；原始语音字节未变。

[当前音频清单](audio/manifest.json)、[原配音计划及记录](audio-origin/)与[视频收据](overview.mp4.json)分别保留绑定和来源。只外发了已批准旁白及必要声线参数，没有外发研究、源码或截图。服务条款及其他再分发用途需使用者自行确认。

新版[浏览器及媒体记录](../../evals/examples/refresh-20260916/project-overview/)和[最终排版复查](../../evals/examples/refresh-20260916/final-visual-review.json)区分结构、实际画面与人的判断。试片已由用户听看确认；完整视频听看、独立真人理解与翻译验收仍未确认。

旧版六幕视频、独立 GIF、词句对齐工具与其检查记录由 Git 历史保存，不再作为当前项目的一部分，也不沿用旧版的验收结论。当前四种项目使用同一份[研究身份](research/manifest.json)；复现方式、持久媒体环境与许可要求见[统一说明](../README.md)。
