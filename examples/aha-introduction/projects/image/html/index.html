01格陵兰：球面面积 ≠ 地图大小

固定球面墨卡托：假设旋转格陵兰，
球面面积不变，地图轮廓大小改变。
概化边界、极区裁切；不是真实搬移。

02CPython 3.11.15：新串 ≠ 旧串

ASCII 加 U+1F600：新串四字节槽。
旧串不变；UTF-8 中 ASCII 仍一字节。
仅限此码点与版本，不泛指所有 emoji。

03Docker：隐藏路径 ≠ 清除旧层

未压平镜像：whiteout 只隐藏路径，
旧层载荷仍在。同一 RUN 内新建再
删除的临时文件，不进入最终层差异；
不是清空整层，也不回收基础层字节。
