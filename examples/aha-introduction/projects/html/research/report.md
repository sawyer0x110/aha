## Mechanism 2: CPython
The reused CPython dossier pins 3.11.15 to commit 2340a037f7450e70fccfe411e6531afb4d57a312. Its PEP 393 and selected PyUnicode_Concat/PyUnicode_New/header/sizeof readings support a uniform one-, two- or four-byte representation for the resulting compact str. U+1F600 exceeds U+FFFF, so a new result containing it needs four-byte code-point slots, including its ASCII prefix. Concat combines operand representation ranges; this is not a claim that every concat scans all code points. The original immutable str remains unchanged. The source shows schematic slots and exact recorded totals, not 100000 individual cells. Not every emoji, all non-ASCII text, or every Python implementation has this behavior.
